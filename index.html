工作流程 / 01

将整理流程固化为可预览、可执行的标准流程。

先预览、后执行，明确每个文件的识别结果与归档路径，避免在文件管理器中重复拖拽与改名。

  1. 01

    扫描来源目录

    快速读取视频与字幕文件，识别片名、年份、剧集与媒体参数。

    先预览，后执行
  2. 02

    识别并预览

    匹配 TMDB 元数据，批量预览新的命名和目标目录，必要时手动修正。

    识别结果可逐项确认
  3. 03

    链接并持续监控

    按已配置规则创建链接、复制或移动文件，并可写入 Emby NFO 与海报，自动处理后续新增内容。

    一次配置，长期生效

核心能力 / 02

既完成一次整理，
也保持媒体库长期整洁。

无论临时下载、日常补档还是已有媒体库，整理始终遵循同一套规则。

访问 GitHub 项目 ↗

媒体整理引擎 / 03

从一串文件名，读懂一整部作品。

解析片名、年份、季集、分辨率、编码、音轨和发布组；再把这些信息变成可预测的目标路径和命名。

文件解析器 输入 / 输出
$ Dune.Part.Two.2024.2160p.UHD.BluRay.DV.HDR10.HEVC.Atmos-GROUP.mkv
标题Dune: Part Two
年份2024
分辨率2160p
视频HEVC
动态范围DV + HDR10
音轨Atmos
目标命名 Dune Part Two (2024) {2160p HEVC DV Atmos}.strm

整理方式 / 04

同一套规则，
适配不同的存储策略。

选择一种整理方式，查看它在媒体库中的工作方式。

方式 / 01 硬链接

源目录与媒体库共享同一份磁盘数据，整理后不会额外占用空间。

来源/downloads/Dune.Part.Two.2024.mkv
媒体库/media/Movies/Dune Part Two (2024).strm
节省空间，适合同一文件系统内的媒体库整理。

Emby 刮削 / 05

整理完成后，
把元数据写成 Emby 能读的文件。

匹配到 TMDB 后，按 Emby 目录规范写入 NFO 与海报。已有文件不会覆盖；也可只下载图片，把剧情交给 Emby。

输出 / 01 电影 NFO 与海报

独立电影目录写入同名 NFO，以及 poster、fanart、logo；已存在的文件会跳过。

NFODune Part Two (2024).nfo
海报poster.jpg · fanart.jpg · logo.png
标题、简介和海报语言可选中文优先或原语言优先。

支持范围 / 06

电影、剧集与字幕，统一进入同一条整理流程。

内容类型 电影 · 剧集 · 混合目录

可按电影、剧集或混合目录运行；剧集会识别季、集与多集范围。

视频与 STRM 17 种扩展名

MKV、MP4、AVI、MOV、M2TS、ISO、TS、WEBM、WMV、FLV、RMVB、OGM、DIVX、M4V、MPG、MPEG、STRM。

字幕跟随 7 种字幕格式

SRT、ASS、SSA、SUB、VTT、SUP、IDX 会随视频整理到对应目录。

命名模板字段 / 07

目录、季目录和文件名，按你需要的字段组合。

支持可视化轨道与 Jinja 风格模板；电影和剧集可分别定义路径。

片名

中文片名、英文片名、原文片名、保留原始文件名。

年份与 ID

带括号年份、纯年份，以及花括号、方括号、短横线三种 TMDB ID 格式。

季与集

S01E01、S01E01-E03、中文季集、Season 01、S01 等多种格式。

画质与编码

分辨率、来源、流媒体、HDR/DV、版本、视频编码、帧率与发布组。

音频

音频格式与音轨数，例如 TrueHD、DDP、AAC、FLAC、Multi。

路径结构

目录分层、空格、点、短横线、中圆点、下划线等分隔符都可组合。

部署方法 / 10

用 Docker 拉起服务，
把媒体目录挂进容器。

提供 Docker 命令和 Docker Compose 两种方式。镜像已发布到 Docker Hub，把宿主机媒体目录挂载进去即可使用。

docker run

在已安装 Docker 的机器上直接执行。将 /your/media 换成你的媒体根目录。


          

        


        

          

            01
            媒体目录
            
将 /your/media 换成宿主机上的媒体根目录。硬链接要求来源和目标位于同一挂载点，例如都放在该目录的子文件夹中。

          

          

            02
            数据与授权
            
./data 保存配置、数据库和授权。请持久化该目录，容器重建后设置仍在；清空或更换目录后需重新激活。

          

          

            03
            打开控制台
            
启动后访问 http://localhost:8080。若 8080 已被占用，把左侧主机端口改成空闲端口即可，例如 18080:8080。

          

        

      


      

        

          

            
配套推荐 / 11

            
优先推荐这些项目，
和 StrmTool 一起补齐链路。

          

          

            StrmTool 负责把文件整理进媒体库。网盘 STRM 生成、Emby 直链播放，可以交给下面这两个独立项目。
          

        


        

          
            
优先推荐STRM 生成

            
SmartStrm

            
从夸克、115、天翼等网盘生成 STRM，给 Emby、Jellyfin、Plex 提供 302 直链入库与播放。

            
配合方式：先用 SmartStrm 把云盘资源写成 .strm，再用 StrmTool 按模板整理进媒体库。

            打开 SmartStrm ↗
          
          
            
优先推荐Emby 插件

            
MediaInfoKeeper

            
Emby STRM 插件：直链播放、媒体信息持久化、元数据刷新，减少 strm 入库后的识别和播放问题。

            
配合方式：StrmTool 整理好库结构后，用 MediaInfoKeeper 稳住 Emby 端的播放与媒体信息。

            查看 GitHub ↗
          
        

        
以上项目由各自作者独立维护，与 StrmTool 没有从属关系；推荐是因为它们能补上整理之后的生成与播放环节。
